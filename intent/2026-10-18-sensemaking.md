# Intent: 헤드라인 모음 → 세계 흐름 이해 (관점 비교 중심 개편)

작성: 사용자 대화 → Claude 정리, 2026-10-18 · 상태: accepted (2026-10-19 "개발시작하자")

## 문제
"내가 이 프로젝트를 하는 이유는 관점을 넓혀 보고 싶어서야" / "생각보다 상상했던것보다 쉽게 와닿진 않네"
- 지금은 헤드라인을 많이 모으기만 한다. 영어 제목을 읽는 데 힘이 들고, 맥락("왜 중요한가")과 연속성(어제 → 오늘)이 없다. 같은 사건을 나라마다 어떻게 다르게 말하는지도 보이지 않는다.
- "ai를 붙여서라도 사람에게 흥미가 (눈에 보이는 이미지까지) 더 끌리게 되고 내가 더 자주 보게되고 더 내가 쉽게 세계의 흐름을 파악할 수 있을까?"

## 원하는 결과 (단계별, 모두 0원)
1. **사건 중심 첫 화면**: 대표 이미지가 들어간 사건 카드와 "지금" 세계 지도(나라별 기사량·이슈). AI·DB 없이 만든다.
2. **AI 보강 파이프라인 (북극성: 나라별 관점 비교 카드)**: 매시간 상위 사건 30~50개를 처리해 한국어 3줄 요약, 나라별 시각 비교(근거 기사 링크 포함), 엔티티를 만든다. 결과는 저장해 두고 `/api/insights`로 제공한다.
3. **시간축**: 사건 타임라인, 급상승 감지, 텔레그램 아침 브리핑(pub/sub).
4. **온톨로지**: 엔티티 관계도, "내 질문"(질문 단위 추적과 주간 변화 정리), GDELT 논조 결합.

## 영향받는 사용자·시스템
- 구조 전환: 요청 시 당겨 오는 방식(request-reply)에서 서버가 주기적으로 수집 → 정규화 → 보강 → 묶기 → 저장하는 이벤트 파이프라인으로 바꾼다 (EIP: Normalizer, Content Enricher, Aggregator, pub/sub).
- 새 외부 요소: GitHub Actions 스케줄(매시간), 무료 LLM API, 무료 DB, 텔레그램 봇, GDELT.
- `InsightEngine`/`Insights` 타입(ADR-013)을 AI 엔진으로 교체할 지점으로 쓴다.

## 제약
- **돈이 안 나가는 기준**. 무료 티어만 쓰고 결제 수단은 등록하지 않는다.
- AI 결과에는 반드시 근거 기사 링크를 붙인다. AI 생성 이미지는 쓰지 않는다(사실 왜곡 위험). 이미지는 기사 og:image를 쓴다.
- API 키는 GitHub/Vercel 비밀값에만 둔다. 채팅이나 저장소에 남기지 않는다.
- "하루에 사건 하나를 세 나라 시각으로 깊게 읽기"는 사람의 몫이다. 도구는 그 습관이 3분 안에 가능하도록 돕는다.

# Intent: 앱처럼 편하게 보기 + 어두운 디자인

작성: 사용자 요청 → Claude 정리, 2026-10-19 · 상태: done (2026-10-19 배포)

## 문제
"웹 이미지를 앱으로도 볼떄 편하게 개편해줘 좀 디자인도 좀 어두운 배경으로 해보고싶어"
- 지금 화면은 데스크톱 웹 기준이다. 폰에서 홈 화면에 설치(PWA, ADR-010)해서 열어도 사이드바 메뉴·작은 전환 버튼·모달 창 위주라 엄지로 쓰기 불편하다.
- 색은 밝은 SaaS형이 기본이고, 다크 모드는 기기 설정을 따를 때만 나온다.

## 원하는 결과
1. **어두운 디자인**: 어두운 배경을 기본으로 하고, 사진·사건 카드가 돋보이는 "뉴스룸" 느낌으로 다듬는다. 강조색 파랑(#2563EB 계열)과 "보라·글로우·블러 금지" 원칙은 유지한다.
2. **앱처럼 보기 (폰·설치형)**:
   - 아래쪽 탭 바: 세계 흐름 / 패널 / 헤드라인 벽 / 키워드 / 더보기
   - 사건 상세와 원문은 아래에서 올라오는 전체 화면 시트로 열고, 쓸어내려 닫기
   - 사건 카드는 사진이 크게 보이는 세로 피드로
   - 상단 바 간소화, 노치·홈 바 안전 영역(safe-area) 반영, 터치 영역 44px 이상
   - 설치형으로 열면 상태 표시줄 색을 어두운 배경에 맞춘다
3. 데스크톱 화면도 같은 어두운 디자인을 쓰되, 지금 배치(사이드바 + 그리드)는 유지한다.

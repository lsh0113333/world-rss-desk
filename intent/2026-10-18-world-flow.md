# Intent: 한 번에 세계 흐름 잡기 + 내 입맛 추천 (1차, 무료)

작성: 사용자 요청 → Claude 정리, 2026-10-18 · 상태: done (2026-10-18 배포)

## 문제
"빠르고 한방에 많이 흐름을 확 캐치할 수 있도록 / 데이터 분석도 좀 들어가서 사용자 입맛에 맞게 바로바로 추천하는 이런것도"
- 패널이 많아질수록 같은 소식이 여러 번 보이고, 어떤 이슈가 여러 나라에서 동시에 다뤄지는지 한눈에 안 보인다.

## 원하는 결과 (1차 묶음, 순서대로)
1. **같은 소식 묶기**: 여러 매체가 같은 소식을 내면 한 줄로 합치고 "+N개 매체"로 표시한다.
2. **오늘의 이슈**: 모든 패널 기사에서 공통 키워드를 묶어 "몇 개 나라가 같은 이야기를 하는지" 순위로 보여 준다. 누르면 나라별로 나란히 비교한다.
3. **헤드라인 벽**: 사진 없이 국기+제목만 여러 열로 깔아 한 화면에 최대한 많이. 보드별로 "패널 / 헤드라인 벽" 전환.
4. **키워드 워치**: 관심 키워드를 등록하면 모든 패널에서 강조하고, 상단에 "새 언급 N건".
5. **개인화 추천**: 읽은 기사 기록으로 선호 나라·분야·매체·키워드를 계산해 "추천" 기사와 "패널 추가 제안"을 보여 준다.

## 영향받는 사용자·시스템
- 새 순수 로직: `src/lib/keywords.ts`, `story-cluster.ts`, `trending.ts`, `recommend.ts`, `watch.ts`
- 화면: Dashboard 상단(이슈·추천), 패널(+N 매체, 키워드 강조), 헤드라인 벽, 상단 바(키워드)
- 데이터: `Layout.watchKeywords`, `Board.view`, 읽기 기록에 나라·분야·매체·키워드 추가 (Repository 경유)

## 제약
- **돈이 안 나가는 기준**. 모든 계산은 브라우저 안에서 (서버 저장·개인정보·비용 없음).
- **AI(2차) 확장을 고려**: "추후에 개선할 생각도 있어 무료수준으로 차근차근". 묶기·이슈 계산을 함수 하나(엔진)로 분리해, 나중에 같은 타입을 돌려주는 `/api/insights`(무료 LLM 등)로 바꿔 끼울 수 있게 한다.
- 한국어·영어 기사를 같은 이슈로 묶는 것은 1차에서는 어렵다 (2차 AI의 몫).

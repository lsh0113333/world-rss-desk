# 나에게 한 문장 (3단계)

사이트 맨 위의 "나에게 한 문장"을 쓰는 법(1부)과 어떻게 만들었는지(2부). 결정 이유는 `docs/ADR.md`의 ADR-024에 있다.

---

## 1부. 사용법

### 처음 한 번 정하기
1. https://world-rss-desk.vercel.app 을 연다.
2. 맨 위 **"나에게 한 문장"** 칸에서 **내 상황 정하기**를 누른다.
3. 해당하는 상황에 체크한다.
   - **IT 업무**: 사이버 보안, 빅테크 규제, 반도체, AI 경쟁 소식을 업무 관점으로 알려 준다.
   - **해외 일정**: 가는 나라를 고르고 **일정 추가**를 누른다. 돌아오는 날은 넣지 않아도 된다. 넣으면 그날이 지난 뒤 자동으로 빠진다. 나라는 5개까지 넣을 수 있다.
4. **완료**를 누르면 바로 한 문장이 나온다.

### 읽는 법
- **맨 위 굵은 문장**이 지금 가장 먼저 확인할 일이다. 안전(해외 일정)이 업무보다 먼저 나온다.
- 그 아래 작은 문장 최대 2개는 더 확인할 일이다.
- **근거 보기**를 누르면 다음이 나온다.
  - 왜 이 문장인지: 어떤 상황과 어떤 사건 유형이 어떤 규칙에 걸렸는지 (예: `해외 일정(프랑스) × 시위·소요 → 규칙 travel-protest`)
  - 근거 사건: 요약, 보도한 나라, 원문 기사 링크
- "지금 내 상황에 걸리는 큰 일은 없어요"가 나오면 지금은 확인할 일이 없다는 뜻이다.
- 상황판은 30분마다 바뀌어서 문장도 따라 바뀐다.

### 바꾸기와 지우기
- 오른쪽 위 **내 상황 바꾸기**를 누르면 고칠 수 있다. 다 지우려면 **나 지우기**를 누른다.

### 알아 둘 것
- 내 상황은 **지금 이 브라우저에만** 저장된다. 서버로 보내지 않는다. 그래서 폰과 PC에서 각각 따로 정해야 한다.
- 문장은 "~확인해 보세요" 수준의 권고다. 판단하기 전에 근거 기사를 직접 확인한다.
- 2개 나라 이상이 보도한 일만 문장으로 만든다. 한 나라만 보도한 작은 사고는 걸리지 않는다.

### 피드백 주실 때
이런 의견을 주시면 바로 고칠 수 있다.
- 이 문장은 엉뚱했다 (근거 보기에 나온 규칙 이름을 같이 알려 주면 좋다)
- 이런 일은 걸렸어야 했다
- 문구가 어색하다
- 이런 상황도 넣고 싶다 (돈, 한국 생활 등)

---

## 2부. 기술 안내

### 한 줄 요약
세계 상황판(파이프라인이 30분마다 만듦) × "나" 객체(브라우저 저장) → **규칙**으로 걸리는 사건을 고르고 **문장 틀**에 끼운다. 계산은 브라우저에서 순수 함수로 하고, AI와 서버 저장은 쓰지 않는다.

```
[서버] 파이프라인 → board_snapshots → /api/world (사건, 점수, 보도 나라, 일어난 나라, 큰 흐름)
                                          │ SWR로 읽기
[브라우저]                                 ▼
  localStorage ── BoardPrefsRepository ── useMe() ── "나" { situations, trips }
                                          │
                     adviseMe(나, 사건들, 오늘)  ← 규칙·문장 틀: src/ontology/me.ts
                                          │
                                   MeCard (메인 맨 위)
```

### 파일
| 파일 | 역할 |
|---|---|
| `src/ontology/me.ts` | **기준(설정)**: 상황 종류와 우선순위(`SITUATIONS`), 권고 규칙과 문장 틀(`ADVICE_RULES`), 숫자(`ME_RULES`: 최소 보도 나라 2, 더 보여 줄 수 2, 일정 나라 5) |
| `src/types/me.ts` | 타입: `Me`, `Trip`, `Advice` |
| `src/lib/ontology/me.ts` | **판단(순수 함수)**: `parseMe`(저장값 검증), `activeTrips`(지난 일정 빼기), `adviseMe`(사건 → 한 문장 목록) |
| `src/lib/board-prefs.ts` | 저장: `BoardPrefsRepository.loadMe/saveMe` (localStorage 키 `world-rss-desk:me`) |
| `src/hooks/useMe.ts` | 화면용 훅: 읽기, 고치기, 저장 |
| `src/components/MeCard.tsx` | 화면: 상황 고르기, 한 문장, 근거 보기 |
| 테스트 | `src/lib/ontology/me.test.ts`, `src/lib/board-prefs.test.ts`, `src/components/MeCard.test.tsx` |

### 판단 순서 (`adviseMe`)
1. 2개 나라 이상이 보도한 사건만 본다 (`ME_RULES.minCountries`).
2. 사건마다 `ADVICE_RULES`를 위에서부터 보고 **처음 맞는 규칙 하나**만 쓴다.
   - 내가 고른 상황의 규칙이어야 한다.
   - 사건 유형(`types`)이나 큰 흐름(`flows`) 중 하나가 맞아야 한다.
   - 해외 일정 규칙은 사건이 일어난 나라가 지금 유효한 일정 나라여야 한다.
3. 문장 틀에 끼운다.
   - 해외 일정: `가시는 {나라}에서 {사건 제목} 소식이 있어요({N}개 나라 보도). {권고}.`
   - IT 업무: `{큰 흐름}: {사건 제목} 소식이 있어요({N}개 나라 보도). {권고}.`
4. 정렬: 상황 우선순위(해외 일정 2 > IT 업무 1) → 상황판 점수(`score.total`).
5. 화면은 첫째를 크게, 다음 2개를 작게 보여 준다.

### 기준 바꾸는 법 (코드 한 파일)
- 문구를 바꾸려면 `src/ontology/me.ts`의 `advice` 문자열을 고친다.
- 규칙을 더하려면 `ADVICE_RULES`에 `{ id, situation, when: { types | flows }, advice }`를 넣는다. 위에 있을수록 먼저 맞는다.
- 상황을 더하려면(예: 돈) `SITUATIONS`에 넣고 그 상황의 규칙을 추가한다. 편집기 체크박스는 자동으로 생긴다.
- 고친 뒤에는 `npm run test`를 돌리고 배포한다(`npx vercel deploy --prod --yes`). 파이프라인은 다시 돌릴 필요 없다.

### 지킨 규칙 (CLAUDE.md)
- **판단은 규칙, AI는 쓰지 않는다**: 같은 입력이면 늘 같은 문장이고, 걸린 규칙을 화면에 보여 준다.
- **사용자 데이터는 Repository로만**: 나중에 4단계(로그인)에서 구현체만 서버 저장으로 바꾼다.
- **근거를 붙인다**: 모든 문장에 근거 사건과 원문 기사가 따라온다.
- **화면은 `/api/world`만 읽는다**: 파이프라인과 API는 바꾸지 않았다.

### 만들면서 바꾼 것
- 실제 데이터로 미리 보니 넓은 "기업·기술 전체" 규칙이 드라마 제작 소식에 업무 권고를 붙였다. 그래서 그 규칙을 지웠다.
- 한 나라만 보도한 화재에 "교통·숙소 확인"이 붙었다. 그래서 최소 보도 나라를 2개로 정했다.

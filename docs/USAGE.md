# 사용법

사이트: https://world-rss-desk.vercel.app · PC와 폰 모두 된다. 가입이나 설치는 없다.
어떻게 돌아가는지는 [`ARCHITECTURE.md`](ARCHITECTURE.md), 판단 기준은 [`ONTOLOGY.md`](ONTOLOGY.md).

---

## 1. 30초 보기 (메인 `/`)

위에서 아래로 "나 → 세계 → 변화 → 지역" 순서다. **처음엔 제목만 보이고, 누르면 펼쳐진다.**

| 칸 | 보는 것 |
|---|---|
| 맨 위 | 갱신 시각("12분 전 갱신"), 지난 방문 이후 새 사건 수, 내 기준 적용 중이면 표시 |
| **나에게 한 문장** | 내 상황에 걸리는 일과 할 일 한 문장 (2절) |
| **지금 흐름** | 지켜보는 큰 흐름 8개(AI 경쟁, 반도체, 사이버 보안, 빅테크 규제, 우크라이나, 중동, 미·중, 한반도). ▲ 커지는 중 / – 유지 / ▼ 잦아드는 중 / 조용. 누르면 그 흐름의 사건들 |
| **세계 5** | 여러 나라가 함께 보도한 가장 큰 일 5개 (스포츠·연예 제외) |
| **IT 5** | 기업·기술 분야 상위 5개 |
| **어제와 달라진 것** | 24시간 전과 비교해 새로 오른 일, 커진 일("3개 나라에서 9개 나라로"), 내려간 일 |
| **대륙별** | 대륙마다 위에 없는 큰 일 3개 + 나라별 1위 |

**사건을 누르면**
- 요약 한 문장, 일어난 곳, 보도한 나라·매체·기사 수
- **왜 이 순위?**: 점수 계산 그대로 (보도 규모 × 유형 배수 + 떠오름)
- **관계로 보기**: "누가 → 누구에게" 행위자. 이름을 누르면 행위자 페이지
- **연관 사건**: 같은 행위자나 같은 흐름으로 이어진 다른 사건과 이유
- **근거 기사 (원문)**: 원문 링크 (새 탭)

"새" 표시는 30분 넘게 지나 다시 왔을 때, 지난 방문 이후 처음 나온 사건에 붙는다.

## 2. 나에게 한 문장

### 처음 한 번 정하기
1. **나에게 한 문장** 칸에서 **내 상황 정하기**를 누른다.
2. 해당하는 상황에 체크한다.
   - **IT 업무**: 사이버 보안, 빅테크 규제, 반도체, AI 경쟁 소식을 업무 관점으로 알려 준다.
   - **해외 일정**: 가는 나라를 고르고 **일정 추가**를 누른다. 돌아오는 날은 넣지 않아도 되고, 넣으면 그날이 지난 뒤 자동으로 빠진다. 5개 나라까지.
3. **완료**를 누르면 바로 한 문장이 나온다.

### 읽는 법
- **굵은 문장**이 지금 가장 먼저 확인할 일이다. 안전(해외 일정)이 업무보다 먼저 나온다.
- 그 아래 작은 문장(최대 2개)은 더 확인할 일이다.
- **근거 보기**를 누르면 "왜 이 문장"(예: `해외 일정(프랑스) × 시위·소요 → 규칙 travel-protest`)과 근거 사건, 원문 기사가 나온다.
- "지금 내 상황에 걸리는 큰 일은 없어요"는 지금은 확인할 일이 없다는 뜻이다.
- 2개 나라 이상이 보도한 일만 문장이 된다. 문장은 "~확인해 보세요" 수준의 권고이니 근거 기사를 직접 확인한다.

### 바꾸기
**내 상황 바꾸기**에서 고치고, 전부 지우려면 **나 지우기**.

## 3. 관계 (`/relations`, 메인 오른쪽 위 "관계")

- **관계 온도 (최근 7일)**: 누가 누구에게 갈등(🔴 공격·제재·비난) 또는 협력(🔵 협상·원조)했나. 막대의 점이 왼쪽이면 갈등, 오른쪽이면 협력, 가운데면 엇갈림. "갈등 8 · 협력 1"은 사건 수다. 누르면 근거 사건.
- **나라끼리 관심 (최근 24시간)**: 줄은 보도한 나라의 매체, 칸은 일이 일어난 나라. 진할수록 많이 보도했다. 자기 나라 일은 빼고, 한국 매체 줄은 항상 있다.

## 4. 행위자 (`/actors/...`)
사건을 펼쳐 "관계로 보기"에서 이름을 누르면 온다. 그 행위자가 최근 30일에 나온 사건(역할: 주체·대상·참여)과 함께 자주 나온 행위자. 사람·기관이면 이름 아래에 **소속 나라**가 보이고, 누르면 그 나라 페이지로 간다(소속은 2026-11-10 이후 새로 읽은 사건부터 쌓인다).

## 5. 온톨로지 (`/ontology`, 메인 오른쪽 위 "온톨로지")

온톨로지 공부용 페이지. 이 사이트가 실제로 쓰는 값을 그대로 보여 준다.

| 칸 | 내용 |
|---|---|
| 시스템이 도는 순서 | 감지 → 묶기 → 읽기 → 저장 → 판단 → 결과, 이번 실행의 실제 숫자 |
| 객체와 관계 | 객체·관계 종류와 지금 쌓인 개수 |
| 누가 만들었나 | 관계를 AI, 규칙, 설정 중 누가 만들었는지 비율 |
| 판단 규칙 | 점수 공식과 규칙 숫자 |
| **내 기준 정하기** | 사건 유형마다 배수 슬라이더. 바꾸면 오른쪽 "실험 결과 세계 5"가 바로 바뀌고, **이 브라우저에 저장되어 메인 순위에도 반영**된다. 메인 맨 위 "원래대로"나 여기 초기화 버튼으로 되돌린다 |
| 직접 해 보기 | 그래프에 물어볼 수 있는 SQL 예제 (`npm run query`) |

## 6. 알아 둘 것
- **30분마다 갱신**된다. 맨 위 갱신 시각이 2시간을 넘으면 "갱신이 늦어지고 있어요"가 뜬다.
- 내 상황과 내 기준은 **이 브라우저에만** 저장된다. 서버로 가지 않는다. 그래서 폰과 PC에서 따로 정해야 하고, 브라우저 데이터를 지우면 사라진다.
- 사건 제목·요약은 AI(Gemini)가 원문 기사로 만든 한국어다. 틀릴 수 있으니 중요한 일은 근거 기사를 확인한다.
- 매체는 275개, 대부분 영어판이다. 어떤 매체를 왜 넣었는지는 [`FEEDS.md`](FEEDS.md).

## 7. 의견을 줄 때
"근거 보기"에 나온 **규칙 이름**이나 사건 제목을 같이 알려 주면 바로 찾아 고칠 수 있다. 예: "travel-protest 문구가 어색해", "이 사건은 세계 5에 있으면 안 될 것 같아".

# 온톨로지 v0 — 세계 뉴스 분야 (초안)

상태: **초안, 사용자 검토 중** (2026-10-24) · 근거: `intent/2026-10-23-ontology-lab.md`, ADR-017
원칙: 판단은 규칙, AI는 읽기(추출)와 말하기(한 문장)만. 모든 결론에 근거 기사.

## 1. 객체 (무엇이 있나)

| 객체 | 뜻 | 주요 속성 | 만드는 주체 |
|---|---|---|---|
| **대륙** | 7개 (아시아·유럽·북미·중남미·중동·아프리카·오세아니아) | 이름, 색 | 고정 |
| **나라** | 매체 본사가 있는 나라와 사건이 일어난 나라 | 코드, 이름, 대륙, 시간대 | 고정 (카탈로그) |
| **매체** | 시각의 주체 ("어느 나라의 목소리인가") | 이름, 본사 나라, 언어 | 고정 (카탈로그) |
| **기사** | 근거. 모든 판단은 기사로 거슬러 올라갈 수 있어야 한다 | 제목, 링크, 시각, 매체 | 수집 |
| **사건** | "무슨 일이 일어났나"의 단위 | 유형(아래 표), 한국어 제목, 한 문장 요약, 처음·마지막 확인 시각, 상태(떠오름/진행/잦아듦) | 규칙(묶기) + AI(추출) |
| **행위자** | 사건의 "누가 / 누구에게" | 종류(사람/기관/나라/집단), 영어 이름, 한국어 이름, 별칭, 소속 나라 | AI(추출) + 규칙(이름 합치기) |
| **큰 흐름** | 여러 날 이어지는 상황 (예: 우크라이나 전쟁, 미·중 무역 갈등) | 한국어 이름, 관련 나라 | 사람이 정한 목록 + AI 제안 |

B 분야(공공 지원)에서 더해질 객체: 사람(상황), 지원 제도, 자격 조건 — 지금은 정의만 비워 둔다.

## 2. 관계 (어떻게 묶이나)

모든 관계에는 **언제 확인했는지**와 **근거 기사 id**, **누가 만들었는지(규칙/AI)**가 붙는다.

```
대륙 ◀─속함── 나라 ◀─본사── 매체 ──발행──▶ 기사 ──보도──▶ 사건
                                                         │
               ┌──────────── 주체 / 대상 / 참여 ──────────┤──▶ 행위자 ──소속──▶ 나라
               │                                         │
         사건 ──일어난 곳──▶ 나라                          ├──일부──▶ 큰 흐름
                                                         └──연관──▶ 사건   (규칙이 계산)
```

| 관계 | 출발 → 도착 | 만드는 주체 | 비고 |
|---|---|---|---|
| 속함 | 나라 → 대륙 | 고정 | |
| 본사 | 매체 → 나라 | 고정 | |
| 발행 | 매체 → 기사 | 수집 | |
| 보도 | 기사 → 사건 | 규칙(묶기) | 한 기사는 사건 하나에만 |
| 주체 / 대상 / 참여 | 사건 → 행위자 | AI | "누가 누구에게" |
| 일어난 곳 | 사건 → 나라 | AI + 검증 | 카탈로그에 있는 나라만 |
| 소속 | 행위자 → 나라 | AI + 이름 표 | |
| 일부 | 사건 → 큰 흐름 | AI가 목록에서 고름 | 목록에 없으면 "새 흐름 제안"으로 표시 |
| 연관 | 사건 → 사건 | **규칙** | 아래 4절 |

파생 지표 (저장하지 않고 계산): **나라 → 나라 관심** = 나라 A 매체의 기사가 나라 B에서 일어난 사건을 보도한 횟수 (2단계 "누가 누구를 보고 있나").

## 4. 규칙 v0 (판단)

**사건 자격**
- 나라 사건: 같은 나라 매체 **2곳 이상**이 보도
- 세계 사건: **2개 이상 나라**의 매체가 보도

**중요도 점수** (같은 입력이면 항상 같은 점수)
```
점수 = 3 × 보도한 나라 수
     + 2 × 보도한 대륙 수
     + 1 × 보도한 매체 수 (최대 10)
     + 유형 가중치
     + 3 (최근 3시간 기사 수가 그 전 3시간의 2배 이상이면, "떠오름")
```

**화면에 올리는 규칙**
- "오늘의 세계": 세계 사건 점수 상위 5개
- 대륙별: 그 대륙 나라에서 **일어난** 사건 점수 상위 3개
- 나라별: 그 나라에서 일어난 사건 상위 3개 (나라 사건 포함)

**연관 규칙**
- 두 사건이 나라·기관 행위자를 **1개 이상 공유**하거나 **같은 큰 흐름**에 속하면 연관
- 강도 = 공유 행위자 수 + (같은 큰 흐름이면 2)
- 사건마다 연관은 최대 2개까지, **다른 대륙의 사건을 우선**한다 (흐름을 보여 주려는 목적)
- "미국", "UN"처럼 너무 자주 나오는 행위자 하나만 겹치면 연관으로 보지 않는다 (하루 사건의 20% 이상에 등장하면 흔한 행위자)

**상태**
- 떠오름: 처음 확인 후 6시간 이내 또는 "떠오름" 조건
- 진행: 최근 12시간 안에 새 기사
- 잦아듦: 12시간 넘게 새 기사 없음 → 화면에서 내려간다

## 5. AI 추출 계약 (읽기)

입력: 규칙으로 묶은 사건 하나의 기사 제목·요약 목록(기사 id 포함).
출력(JSON, 스키마 강제):
```
유형: 3절 목록 중 하나
제목: 한국어 한 줄 (30자 안팎)
요약: 한국어 한 문장 ("누가 누구에게 무엇을")
행위자: [{ 이름(영어), 한국어 이름, 종류, 역할(주체/대상/참여), 소속 나라 }]
일어난 곳: [나라 코드]
큰 흐름: 목록 중 하나 또는 "새 흐름 제안: <이름>"
근거: [기사 id]
```
검증: 유형·나라·역할이 목록에 있는지 확인하고, 근거 id가 실제 입력 기사인지 확인한다. 어긋나면 그 항목을 버린다.

## 6. 저장 (Supabase, 분야 무관)

- `objects(id, type, props jsonb, first_seen, last_seen)`
- `links(src, type, dst, props jsonb, observed_at, evidence text[], made_by)`
- 객체·관계 종류와 허용되는 출발/도착은 설정 파일(`src/ontology/world.ts`)에 정의하고, 쓸 때 코드가 검증한다. 분야를 바꿀 때는 설정 파일을 하나 더 만든다.
- 기존 테이블(articles, stories, entities 등)은 1단계에서 옮긴다.

## 7. 열린 질문 (사용자 검토)
1. 사건 유형 12개 — 빼거나 더할 것 (예: 기후·환경, 이민·난민, 보건을 따로?)
2. 유형 가중치 — "무엇이 더 중요한가"는 사람의 판단. 예: 경제를 무력 충돌만큼 올릴지
3. 큰 흐름 시작 목록 — 지금 추적하고 싶은 상황 (예: 우크라이나 전쟁, 가자 분쟁, 미·중 갈등, 한반도)
4. 나라 사건(국내 뉴스)도 나라별 상위에 올릴지 — 기본안은 올린다

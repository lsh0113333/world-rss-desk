# 온톨로지 v1 — 세계 뉴스 분야

상태: **v1, 코드와 일치** (2026-11-01). 숫자의 원본은 `src/ontology/world.ts`. 근거: `intent/2026-10-23-ontology-lab.md`, ADR-017·019
원칙: 판단은 규칙, AI는 읽기(추출)와 말하기(한 문장)만. 모든 결론에 근거 기사.

## 1. 객체 (무엇이 있나)

| 객체 | 뜻 | 주요 속성 | 만드는 주체 |
|---|---|---|---|
| **대륙** | 7개 (아시아·유럽·북미·중남미·중동·아프리카·오세아니아) | 이름, 색 | 고정 |
| **나라** | 매체 본사가 있는 나라와 사건이 일어난 나라 | 코드, 이름, 대륙, 시간대 | 고정 (카탈로그) |
| **매체** | 시각의 주체 ("어느 나라의 목소리인가") | 이름, 본사 나라, 언어 | 고정 (카탈로그) |
| **기사** | 근거. 모든 판단은 기사로 거슬러 올라갈 수 있어야 한다 | 제목, 링크, 시각, 매체 | 수집 |
| **사건** | "무슨 일이 일어났나"의 단위 | 유형(아래 표), 한국어 제목, 한 문장 요약, 처음·마지막 확인 시각 | 규칙(묶기) + AI(추출) |
| **행위자** | 사건의 "누가 / 누구에게" | 종류(사람/기관/나라/집단), 영어 이름, 한국어 이름 | AI(추출) + 규칙(이름 합치기) |
| **큰 흐름** | 여러 날 이어지는 상황 (예: 우크라이나 전쟁, 미·중 무역 갈등) | 한국어 이름 | 사람이 정한 목록 (AI는 고르기만) |

B 분야(공공 지원)에서 더해질 객체: 사람(상황), 지원 제도, 자격 조건 — 지금은 정의만 비워 둔다.

## 2. 관계 (어떻게 묶이나)

모든 관계에는 **언제 확인했는지**와 **근거 기사 id**, **누가 만들었는지(규칙/AI)**가 붙는다.

```
대륙 ◀─속함── 나라 ◀─본사── 매체 ──발행──▶ 기사 ──보도──▶ 사건
                                                         │
               ┌──────────── 주체 / 대상 / 참여 ──────────┤──▶ 행위자
               │                                         │
         사건 ──일어난 곳──▶ 나라                          ├──일부──▶ 큰 흐름
                                                         └──연관──▶ 사건   (규칙이 계산)
```

| 관계 | 출발 → 도착 | 만드는 주체 | 비고 |
|---|---|---|---|
| 속함 | 나라 → 대륙 | 고정 | |
| 본사 | 매체 → 나라 | 고정 | |
| 발행 | 매체 → 기사 | 수집 | |
| 보도 | 기사 → 사건 | 규칙(묶기) | 한 기사는 사건 하나에만 |
| 주체 / 대상 / 참여 | 사건 → 행위자 | AI | "누가 누구에게" |
| 일어난 곳 | 사건 → 나라 | AI + 검증 | 카탈로그에 있는 나라만 |
| 일부 | 사건 → 큰 흐름 | AI가 목록에서 고름 | |
| 연관 | 사건 → 사건 | **규칙** | 아래 4절 |

파생 지표 (저장하지 않고 계산): **나라 → 나라 관심** = 나라 A 매체의 기사가 나라 B에서 일어난 사건을 보도한 횟수 (2단계 "누가 누구를 보고 있나").

## 4. 규칙 v0 (판단)

**사건 자격**
- 나라 사건: 같은 나라 매체 **2곳 이상**이 보도
- 세계 사건: **2개 이상 나라**의 매체가 보도

**중요도 점수** (같은 입력이면 항상 같은 점수)
```
보도 규모 = 3 × 보도한 나라 수 + 2 × 보도한 대륙 수 + 보도한 매체 수(최대 10)
점수     = 보도 규모 × 유형 배수 + 5 (최근 3시간 기사가 그 전 3시간의 2배 이상이고 2건 이상이면, "떠오름")
```
처음에는 더하기였으나 시안에서 나라 수가 점수를 다 결정해 유형이 힘을 못 썼다. 그래서 곱하기로 바꿨다 (ADR-019).

**같은 사건 합치기**: 제목 단어가 70% 이상 겹치면 같은 사건으로 합친다. 기사·행위자·장소를 합치고 기사가 많은 쪽이 대표가 된다.

**화면에 올리는 규칙**
- 세계 5: 세계 사건 점수 상위 5개 (스포츠·연예 제외)
- IT 5: 기업·기술 사건 점수 상위 5개 (세계 5와 겹치지 않게, 국내 사건 포함)
- 대륙별: 그 대륙 나라에서 **일어난** 사건 중 세계 5·IT 5에 없는 상위 3개
- 나라별: 그 나라에서 일어난 사건 (나라 사건 포함, 사용자 결정). 화면에는 1위만

**큰 흐름 시작 목록** (사용자 결정: IT 최우선, 나머지는 제안 유지)
1. AI 경쟁 (빅테크·AI 모델·AI 규제)
2. 반도체 공급망·수출 통제
3. 사이버 보안·해킹
4. 빅테크 규제 (EU 디지털 규제, 반독점)
5. 우크라이나 전쟁
6. 가자·중동 분쟁
7. 미·중 갈등
8. 한반도 정세

**연관 규칙**
- 두 사건이 나라·기관 행위자를 **1개 이상 공유**하거나 **같은 큰 흐름**에 속하면 연관
- 강도 = 공유 행위자 수 + (같은 큰 흐름이면 2)
- 사건마다 연관은 최대 2개까지, **다른 대륙의 사건을 우선**한다 (흐름을 보여 주려는 목적)
- "미국", "UN"처럼 너무 자주 나오는 행위자 하나만 겹치면 연관으로 보지 않는다 (하루 사건의 20% 이상에 등장하면 흔한 행위자)

**상태**
- 떠오름: 위 조건
- 잦아듦: 12시간 넘게 새 기사 없음 → 화면에서 내려간다

**큰 흐름 추세**: 최근 6시간 기사 ÷ 그 전 6시간 기사. 1.3 이상 커지는 중, 0.7 이하 잦아드는 중, 사건이 없으면 조용

## 5. AI 추출 계약 (읽기)

입력: 규칙으로 묶은 사건 하나의 기사 제목·요약 목록(기사 id 포함).
출력(JSON, 스키마 강제):
```
유형: 3절 목록 중 하나
제목: 한국어 한 줄 (30자 안팎)
요약: 한국어 한 문장 ("누가 누구에게 무엇을")
행위자: [{ 이름(영어), 한국어 이름, 종류, 역할(주체/대상/참여), 나라 코드(종류가 나라일 때) }]
일어난 곳: [나라 코드]
큰 흐름: 목록 중 하나 또는 빈 값
근거: [기사 id]
```
검증: 유형·나라·역할이 목록에 있는지 확인하고, 근거 id가 실제 입력 기사인지 확인한다. 어긋나면 그 항목을 버린다. 묶음에 다른 사건이 섞여 있으면 AI가 사건별로 나누고, 나눈 사건은 근거 2건 이상일 때만 남긴다. 나라 행위자는 코드로(`country:US`), 나머지는 정리한 영어 이름으로(`actor:org:un`) 합친다.

## 6. 저장 (Supabase, 분야 무관)

- `objects(id, type, props jsonb, first_seen, last_seen)`
- `links(src, type, dst, props jsonb, observed_at, evidence text[], made_by)`
- 객체·관계 종류와 허용되는 출발/도착은 설정 파일(`src/ontology/world.ts`)에 정의하고, 쓸 때 코드가 검증한다. 분야를 바꿀 때는 설정 파일을 하나 더 만든다.
- 기사는 양이 많아 `articles` 테이블에 두고, 관계에서는 `article:<id>`로 가리킨다.
- 연관과 관심 행렬은 저장하지 않고 계산한다.

## 7. 결정 기록
- 2026-10-24: 유형 12개, IT 최우선, 큰 흐름 8개, 국내 뉴스도 나라별 상위에.
- 2026-11-01: 스포츠·연예를 세계 5에서 뺀다 → 사회·문화에서 나누어 13개가 되었다. 점수를 더하기에서 곱하기로 바꾸고 같은 사건 합치기를 추가했다 (ADR-019).

## 8. 공부 메모
- 이 온톨로지는 "사람이 세상을 보는 기준"을 옮겨 적은 것이다. 순위가 마음에 안 들면 `src/ontology/world.ts`의 숫자가 곧 그 기준이다.
- 정의(스키마)와 사실(데이터)을 나눈다: 정의는 `world.ts`, 사실은 `objects`, `links`.
- `/ontology`의 내 기준 정하기에서 배수를 바꿔 보고, `npm run query`로 관계를 직접 물어보면 구조가 잘 보인다.

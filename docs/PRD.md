# PRD: World RSS Desk

## 목표
여러 나라의 주요 이슈를 **한 화면에서 5분 안에** 훑어 매일 세계 흐름을 잡는다.

## 사용자
- 본인 1명. 하루에 여러 번 PC와 폰에서 접속한다.
- 한국어 사용자지만 영어 헤드라인은 읽을 수 있다.

## 핵심 개념
| 개념 | 설명 |
|------|------|
| 카탈로그 피드 | repo에 큐레이션된 매체 RSS 하나. 대륙·나라·분야·언어 태그가 붙어 있다 |
| 커스텀 피드 | 사용자가 직접 입력한 RSS URL |
| 패널 | 화면의 박스 하나. 피드 여러 개를 합쳐 최신순 N개 헤드라인을 보여준다. 보통 "나라 × 분야" (예: 🇰🇷 경제) |
| 레이아웃 | 패널 목록과 순서. localStorage에 저장된다 |

## 분류 체계
- **대륙**: `asia`, `europe`, `north-america`, `south-america`, `middle-east`, `africa`, `oceania`, `global`(국제 매체)
- **나라**: ISO 3166-1 alpha-2 코드 (`KR`, `US`, `JP` …). 지역 단위는 `EU`(유럽)·`ME`(중동)·`ASIA`·`LATAM`·`AFRICA`, 국제 매체는 `WORLD`. 현재 55개 (목록: `docs/FEEDS.md`)
- **분야** 11개: `top`(종합), `world`(국제), `politics`(정치), `economy`(경제), `society`(사회), `tech`(IT), `science`(과학), `health`(건강), `environment`(환경·기후), `culture`(문화·연예), `sports`(스포츠)

## 핵심 기능
1. **패널 그리드**: 메인 화면에 패널을 격자로 배치한다. 패널마다 여러 매체를 합쳐 링크 기준으로 중복을 제거하고 최신순 N개(기본 10, 5~30)를 보여준다.
2. **패널 추가/편집/삭제**: 대륙 → 나라 → 분야를 고르면 해당 카탈로그 피드가 자동 선택된다. 매체별 체크박스로 on/off하고, 커스텀 RSS URL을 추가하고, 패널 제목과 개수를 바꾼다. 순서는 ←/→ 버튼으로 옮긴다.
3. **새 기사 표시**: 패널별 `lastSeenAt` 이후 발행된 기사를 포인트 색으로 강조하고, 헤더에 `+N`을 표시한다.
   - `lastSeenAt` 갱신 시점은 두 가지뿐이다. (a) 패널 헤더의 `+N` 배지 클릭, (b) 상단 바의 "모두 확인" 클릭.
   - 기사 링크 클릭이나 스크롤로는 갱신하지 않는다(의도치 않게 사라지는 것을 막기 위함).
   - 새로 만든 패널은 `lastSeenAt`이 없으므로 강조하지 않는다.
4. **자동 갱신(준실시간) + 수동 새로고침**
   - 페이지가 열려 있는 동안 **2분마다** 자동으로 확인한다(2026-10-17 변경, 기존 10분). 브라우저 탭으로 돌아올 때도 갱신하고, 탭이 숨겨져 있으면 멈춘다.
   - 새로 들어온 기사는 패널 맨 위에 나타나며 3초간 파란 배경으로 강조된다.
   - RSS는 매체가 밀어주는 방식이 없어 완전한 실시간은 불가능하다. 매체의 RSS 갱신 주기(수 분)를 고려하면 2분이 실질적 한계.
   - **수동 새로고침 버튼**은 두 곳에 둔다. (a) 패널 헤더의 ↻: 해당 패널만, (b) 상단 바의 ↻: 모든 패널.
   - 수동 새로고침은 서버 캐시를 건너뛰고 매체에서 바로 다시 받는다(`fresh=1`).
   - 버튼을 누르면 회전 대신 "갱신 중…" 텍스트를 표시하고, 완료 후 30초간 비활성화한다(연타 방지).
   - 패널 헤더에 마지막 갱신 시각(`10:42`)을 표시한다.
5. **설정 저장/이동**: localStorage에 자동 저장한다. 기기 간 이동은 JSON 내보내기/가져오기로 한다.
6. **기본 프리셋**: 첫 방문 시 패널 8개를 채운다: 🇰🇷 종합, 🇰🇷 경제, 🇺🇸 종합, 🇺🇸 IT, 🇯🇵 종합, 🇨🇳 종합, 🇪🇺 유럽 종합, 🌍 국제. 언제든 프리셋으로 초기화할 수 있다.
7. **부분 실패 허용**: 일부 피드가 실패하면 성공한 기사는 보여주고, 패널 하단에 "N개 매체 불러오기 실패"를 표시한다.
9. **분할 화면 + 원문 보기** (2026-10-17 추가)
   - 데스크톱(≥1024px): 왼쪽 절반은 패널 목록(2열), 오른쪽 절반은 선택한 기사의 원문.
   - 기사를 누르면 새 탭 대신 오른쪽에 원문을 띄운다. Ctrl/⌘/가운데 클릭은 기존처럼 새 탭.
   - 원문 표시 순서(하이브리드): ① 매체가 허용하면 실제 페이지(iframe) ② 막으면 서버가 본문만 추출한 **읽기 모드** ③ 그것도 실패(유료벽·차단)하면 "새 탭에서 열기" 안내. 어떤 경우든 상단에 "원문 사이트에서 열기" 링크를 둔다.
   - 모바일: 기사를 누르면 원문이 전체 화면으로 덮이고 "← 목록"으로 돌아간다.
   - 조사 결과(2026-10-17): 33개 매체 중 iframe 허용은 약 9곳(한국 매체 전부, Mainichi, NPR, Arab News, Agência Brasil 등). BBC·NYT·Guardian·Al Jazeera·SCMP 등은 차단.
10. **패널 안에서 매체 바로 선택**
   - 패널 제목 아래에 그 패널의 나라·분야에 해당하는 매체 칩을 나열하고, 눌러서 켜고 끈다(편집 창 불필요).
   - 켜진 칩만 기사 요청에 포함. 최대 12개. 모두 끄면 "선택된 매체가 없습니다".
   - 커스텀 URL은 호스트명 칩으로 표시(켜고 끄기는 편집 창에서 삭제로).
11. **디자인 v2 (2026-10-17)** — 밝은 SaaS형. 상세는 UI_GUIDE.md
   - 왼쪽 사이드바(내 패널 목록 + 새 기사 수, 누르면 해당 패널로 이동), 상단 바
   - "오늘의 톱": 패널마다 최신 기사 1개를 사진 카드로 가로 나열(패널 간 중복 제외)
   - 기사 썸네일: RSS 이미지 → 기사 페이지 og:image(`/api/thumb`) → 매체 이니셜
   - 패널별 보기 방식(카드/목록/텍스트)과 넓게 보기(2칸)
   - 원문은 오른쪽에서 밀려 나오는 서랍(평소 숨김)
12. **쉬운 꾸미기 (2026-10-17)**
   - **온보딩**: 처음 접속하면 관심 나라·분야를 고르는 창 → 고른 조합으로 패널 생성("기본 구성으로 시작"도 가능)
   - **빠른 추가**: `+ 패널` → 나라 → 분야, 2번 클릭이면 패널 생성. 매체 직접 선택·RSS 주소는 "매체 직접 고르기"로 상세 편집 창
   - **명령창(Ctrl/⌘+K)**: "미국 경제", "BBC", "테크"처럼 입력 → 패널 추가/이동, 매체 패널 추가, 보드 전환, 모두 확인·새로고침·내보내기
   - **보드(탭)**: 패널 묶음을 여러 개(최대 10개, 보드당 패널 24개). 사이드바에서 추가·이름 변경·삭제·전환
   - **드래그 앤 드롭**: 패널 헤더를 잡아 다른 패널 위에 놓으면 그 자리로 이동(데스크톱). ←/→ 버튼은 같은 보드 안에서 이동
   - **읽은 기사 흐리게**: 연 기사는 회색으로(최근 3천 개 기록, 브라우저에 저장)
13. **RSS 더 가져오기 (2026-10-18 완료)**
   - 카탈로그 270개 (영어판 원칙, `docs/FEEDS.md`)
   - **사이트 주소로 RSS 찾기**: 편집 창 "RSS 또는 사이트 주소" → 찾은 피드 목록에서 골라 추가 (카탈로그 매체는 카탈로그 피드로)
   - **키워드 패널**: 검색어 하나로 구글 뉴스 RSS 패널 (빠른 추가 키워드 칸, 명령창 마지막 줄, 편집 창). 제목 기본값 "🔎 검색어"
   - **자동 점검**: 매일 06:00(KST) 전체 피드 점검, 설정 메뉴 "피드 상태"
14. **원문 보기 개선 (2026-10-18)** — `intent/2026-10-18-reader-first.md`
   - **읽기 모드 우선**: 본문 추출이 되면 항상 읽기 모드 먼저. iframe이 허용되는 매체는 "읽기 모드 / 원본 페이지" 전환 (해외 매체 iframe이 쿠키 동의 창·유료벽으로 빈 화면이 되던 문제)
   - 못 여는 기사(403·유료벽)는 빈칸 대신 RSS의 제목·사진·요약 카드 + "새 탭에서 열기"
   - "같은 소식, 다른 매체": 같은 사건을 다룬 다른 매체 기사를 아래에 보여 줘 막힌 기사도 다른 곳에서 읽는다
15. **세계 흐름 1차 (2026-10-18, 무료·브라우저 안 계산)** — `intent/2026-10-18-world-flow.md`
   - **같은 소식 묶기**: 패널 안 같은 소식은 한 줄로, "+N개 매체". 오늘의 톱도 같은 소식은 한 번만
   - **오늘의 이슈**: 여러 나라·매체가 함께 다루는 키워드 순위(나라 국기, 기사 수, 최근 1시간 수). 누르면 나라별로 나란히 비교
   - **헤드라인 벽**: 보드별 "패널 / 헤드라인 벽" 전환. 국기+제목만 여러 열, 같은 소식은 한 줄, 최신순
   - **키워드 워치**: 관심 키워드(최대 20개)를 모든 패널·벽에서 강조, 상단 "키워드" 버튼에 안 읽은 언급 수
   - **내 관심사 추천**: 읽은 기사 기록(매체·나라·분야·키워드, 최근 500개, 7일 반감)으로 새 기사 최대 6개 추천 + 많이 읽는 대륙의 나라 패널 추가 제안. 5개 이상 읽으면 시작. 기록은 이 브라우저에만
   - 한국어·영어 기사를 같은 이슈로 묶기, 제목 번역, AI 요약은 **2차(AI, 무료 수준)** 몫. 분석 엔진을 `InsightEngine` 타입으로 분리해 두었다(ADR-013)
8. **홈 화면 설치(PWA)**: 웹 앱 매니페스트와 아이콘을 넣어 폰과 PC에서 "앱처럼" 설치·실행할 수 있게 한다. 오프라인 캐시(Service Worker)는 MVP에서 제외한다.

### 화면과 동작
| 항목 | 정책 |
|---|---|
| 패널당 기사 수 | 기본 10, 패널별 5~30 |
| 자동 갱신 | 10분 + 탭 복귀 시 |
| 오래된 기사 | 발행 72시간이 넘은 기사는 숨긴다 |
| 날짜 없는 기사 | 맨 아래에 표시(72시간 필터 대상 아님) |
| 요약 | 화면에 표시하지 않고 `title` 툴팁으로만 노출 |
| 시간 표시 | 24시간 이내 "12분 전"/"3시간 전", 이후 "10/16 14:20". 브라우저 로컬 시간대 기준 |
| 테마 | 시스템 다크/라이트 자동 |
| 패널 개수 | 최대 24개. 넘으면 `+ 패널` 버튼 비활성화 |
| 패널 간 중복 기사 | 허용(패널 내부에서만 중복 제거) |
| 패널 삭제 | 확인창 없이 즉시 삭제하고, 5초간 "삭제됨 · 되돌리기" 토스트 표시 |

### 예외 처리
| 상황 | 처리 |
|---|---|
| 피드 응답 지연 | 8초 타임아웃 후 실패 처리 |
| 패널 일부 피드 실패 | 성공한 기사를 표시하고 푸터에 "N개 매체 불러오기 실패" (hover 시 매체명과 사유) |
| 패널 전체 실패 | "불러오지 못했습니다" + 다시 시도 버튼 |
| 인터넷 끊김 | 마지막 데이터를 유지하고 상단 바에 "오프라인" 표시(`navigator.onLine` + online/offline 이벤트). 복구 시 자동 갱신 |
| 커스텀 URL 추가 | 저장 전 `/api/feeds?urls=…&limit=1`로 검증. `errors`가 비어 있지 않으면 사유를 보여주고 추가를 막는다 |
| 저장된 설정 손상 | 기본 프리셋으로 복구하고, 원본은 `world-rss-desk:layout-backup`에 보관 |
| JSON 가져오기 | 덮어쓰기 방식(확인창 1회). 검증에 실패하면 에러를 표시하고 기존 설정을 유지 |
| 카탈로그에서 빠진 매체 | 피드 요청에서 제외하고, 편집 화면에 "더 이상 제공되지 않는 매체"로 표시하며 제거 버튼 제공 |
| 인코딩(EUC-KR 등) | 서버에서 charset을 판별해 변환 |

## 운영 전제
- 서비스는 **Vercel(클라우드)에서 24시간 동작**한다. 개발용 노트북을 꺼도 폰과 다른 PC에서 계속 접속할 수 있다.
- 노트북은 개발에만 쓴다. 코드를 GitHub에 push하면 Vercel이 자동으로 빌드·배포한다.
- 비용은 0원이 목표다(Vercel Hobby, GitHub private repo 무료 범위).

## MVP 제외 사항
- 번역 (2단계: 제목만 DeepL 무료 API로 번역 + 캐시, ADR-006)
- 로그인, 서버 저장, 기기 자동 동기화
- ~~기사 본문 스크래핑과 리더 모드~~ → 9번 기능으로 추가됨. 단, 본문은 저장하지 않고 열람 시에만 가져온다(서버 CDN 캐시 1시간 제외)
- 드래그 앤 드롭 정렬 (←/→ 버튼으로 대체)
- 검색, 푸시 알림 (키워드 워치는 15번으로 추가됨)
- AI 요약 (규칙 기반 이슈 묶기는 15번으로 추가됨)
- 읽음 처리 개별 기사 단위 저장 (패널 단위 `lastSeenAt`만 사용)

# PRD: 오늘의 세계 (World RSS Desk)

## 목표
1. **한눈에, 실시간에 가깝게, 빠르게 세계 흐름을 잡는 사이트**
2. **온톨로지를 직접 만들고 공부하는 실험실**

궁극 목표는 "지금 상황이 이러시니 이렇게 하시면 돼요"라는 한 문장 솔루션이다. 세계 뉴스(나를 위한 것)에서 구조를 검증한 뒤 공공 지원 분야로 넓힌다 (`intent/2026-10-23-ontology-lab.md`).

## 사용자
본인 1명. 하루 여러 번 PC와 폰에서 접속한다. 설치 없이 도메인으로 들어온다. IT 분야를 가장 중요하게 본다.

## 원칙
- 단순함: 설명 없이 봐도 알고, 설정이 없다. 답을 먼저 보여 주고 근거는 눌렀을 때 나온다.
- 판단은 규칙, AI는 읽기와 말하기만. 모든 결론에 근거 기사.
- 무료. 결제 수단을 등록하지 않는다.

## 화면
### 오늘의 세계 (`/`)
| 구역 | 내용 |
|---|---|
| 머리 | 갱신 시각, 지난 방문 이후 새 사건 수, 내 기준 적용 표시, 관계·온톨로지 링크 |
| 나에게 한 문장 | 내 상황(해외 일정, IT 업무)을 정하면 걸리는 일 한 문장 + 더 확인할 것 2개. 근거 보기에 걸린 규칙과 사건. 상황은 브라우저에만 저장 |
| 지금 흐름 | 큰 흐름 8개: 추세(커지는 중/유지/잦아드는 중/조용), 사건 수, 대표 사건. 누르면 사건 목록 |
| 세계 5 | 2개 이상 나라가 보도한 사건 상위 5개. 스포츠·연예 제외 |
| IT 5 | 기업·기술 사건 상위 5개 (세계 5와 겹치지 않게) |
| 어제와 달라진 것 | 24시간 전과 비교해 새로 오른 일, 커진 일, 내려간 일 |
| 대륙별 | 7개 대륙, 위에 없는 사건 상위 3개 + 나라별 1위 |
| 사건 펼침 | 요약, 왜 이 순위, 관계로 보기, 행위자 링크, 보도한 나라, 연관 사건, 근거 기사 원문 |

### 관계 (`/relations`)
관계 온도(최근 7일, 누가 누구에게 갈등·협력, 상위 10쌍, 누르면 근거 사건), 나라끼리 관심(최근 24시간, 보도 나라 × 일어난 나라 표, 한국 줄 항상).

### 행위자 (`/actors/[id]`)
그 행위자가 나온 사건과 역할, 함께 나온 행위자. 관계를 따라 다른 행위자로 이동한다.

### 온톨로지 (`/ontology`)
시스템이 도는 순서, 객체·관계 종류와 실제 개수, 누가 만들었는지(AI/규칙/설정), 판단 규칙, 내 기준 정하기(유형 배수를 바꾸면 브라우저에 저장되고 메인 순위에 반영), 직접 해 볼 쿼리.

## 데이터 원천
RSS 카탈로그 275개 피드 (`docs/FEEDS.md`). 매체는 본사가 있는 나라의 시각으로 다룬다. 해외 매체는 영어판 위주이고, 중남미는 현지어 매체도 있다.

## 하지 않는 것 (지금)
사용자가 소스 추가, 패널·보드 꾸미기, 읽기 모드, 휴대폰 알림, 로그인(4단계), 공공 지원(5단계). 로드맵은 `intent/2026-10-23-ontology-lab.md`.

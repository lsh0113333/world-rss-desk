# RSS 수집 기준과 현황

어떤 기준으로 매체를 골랐는지, 지금 어디까지 넣었는지, 무엇을 왜 뺐는지, 더 넣으려면 어떻게 하는지 정리한다.
(2026-10-17 기준. 카탈로그 원본: `src/data/catalog.json`)

## 1. 용어

| 용어 | 뜻 | 예 |
|------|----|----|
| **매체** | 언론사 하나 | BBC News |
| **피드** | 그 매체가 공개한 RSS 주소 하나. 보통 **섹션마다 따로** 있다 | BBC의 `world/rss.xml`, `business/rss.xml`, `technology/rss.xml` … |
| **분야** | 이 앱의 분류 6개 | 종합·국제·정치·경제·IT·과학 |

패널의 매체 칩은 **그 패널의 나라·분야에 맞는 피드만** 보여준다. 그래서 "🇰🇷 한국·경제" 패널에는 칩이 3개뿐이지만, 전체 카탈로그는 아래처럼 더 크다.

## 3. Feedly·Inoreader는 왜 훨씬 많아 보이나

| 이유 | Feedly·Inoreader | 이 앱 |
|------|------------------|-------|
| 섹션 피드 | 매체의 모든 섹션 피드(수십 개)를 노출 | 6개 분야에 맞는 것만 수동 선별 |
| 피드 DB | 수백만 사용자가 추가한 피드를 모은 검색 DB | 직접 검증한 78개 |
| RSS 없는 사이트 | 자체 크롤러로 피드를 만들어 줌(유료 기능 포함) | 공식 RSS만 |
| 집계 피드 | Google News 같은 집계 피드도 제공 | 없음 |

**기술적으로 못 가져오는 게 아니라, 처음에 범위를 6개 분야로 좁혀서 그만큼만 넣은 것이다.** 아래 6번처럼 늘릴 수 있다.

## 4. 수록 기준

카탈로그에 넣으려면 **모두** 만족해야 한다.

1. **언론사가 공식으로 공개한 RSS/Atom** 주소일 것 (사이트를 긁어서 만든 피드는 쓰지 않음)
2. **무료, 로그인 불필요**
3. **실제 접속 성공**: 내 PC(`npm run feeds:check`)와 **Vercel 서버**(배포 후 `/api/feeds?fresh=1&ids=…`) 양쪽에서
4. **살아 있는 피드**: 최신 기사가 72시간 이내
5. **기사에 발행 시각이 있을 것** (정렬·72시간 필터에 필요. 예외: Nikkei Asia — 대체 매체가 없어 수록)
6. 6개 분야 중 하나에 **명확히 대응**할 것
7. 해외 매체는 **영어판 우선** (MVP는 번역 없음)
8. 국영·관영 매체는 넣되 `note`로 표시 (예: CGTN "중국 정부 시각")

## 6. 더 가져올 수 있는 것 (실제 접속 확인함)

| 매체 | 추가 가능한 섹션 |
|------|-----------------|
| 연합뉴스 | 북한, 사회, 문화, 스포츠, 연예, 마켓 |
| 한국경제 | 금융, 부동산, 사회, 스포츠, 연예 |
| BBC News | 건강, 문화·예술, 아시아, 유럽, 스포츠 |
| The New York Times | 건강, 예술, 기후, 아시아·태평양 |
| The Guardian | 환경, 문화, 스포츠, 아시아·태평양, AI (가디언은 거의 모든 섹션·태그에 `/rss`가 있음) |
| **Google News** | 나라별 토픽(경제·IT 등)과 **키워드 검색 결과**(예: "반도체")를 RSS로 제공 |

늘리는 방법은 세 가지다.

| 방법 | 내용 | 비고 |
|------|------|------|
| **A. 분야 확대 + 섹션 추가** | 분야에 사회·문화/연예·스포츠·건강·환경/기후·북한 등을 추가하고, 위 섹션 피드를 카탈로그에 넣음 | 지금 구조 그대로 확장. 카탈로그가 150~250개 규모가 됨 |
| **B. 키워드 패널 (Google News)** | "반도체", "환율"처럼 키워드로 패널을 만들면 여러 매체 기사를 모아 줌 | 링크가 Google 경유 주소라 원문 보기(읽기 모드)가 덜 잘 될 수 있음 |
| **C. 사이트 주소로 RSS 자동 찾기** | 커스텀 추가 칸에 `bbc.com`처럼 사이트 주소만 넣으면, 페이지의 RSS 링크(`<link rel="alternate">`)를 찾아 목록으로 보여줌 | Feedly의 "검색해서 추가"와 비슷한 경험. 지금은 RSS 주소를 정확히 알아야 함 |

## 7. 지금도 할 수 있는 것

- **RSS 주소 직접 추가**: 패널 편집 → "RSS 주소 직접 추가"에 아무 RSS 주소나 넣으면 된다(저장 전에 실제로 받아 보고 검증).

## 8. 점검과 유지보수

```bash
npm run feeds:check          # 78개 피드를 내 PC에서 실제로 받아 OK / STALE / FAIL 표시
```
- 배포 서버에서 다시 확인: `https://world-rss-desk.vercel.app/api/feeds?fresh=1&ids=<피드 id>` → `errors`가 비어야 정상
- 피드 id는 `{나라}-{매체}-{분야}` 형식이며, **사용자 설정이 참조하므로 한번 정하면 바꾸지 않는다.** 피드를 빼면 해당 패널에 "더 이상 제공되지 않는 매체"로 표시된다.
- 매체가 RSS 주소를 바꾸거나 없애는 일은 흔하다. 한 달에 한 번쯤 `feeds:check`를 돌리는 걸 권장.
